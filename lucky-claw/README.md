# 오늘은 뽑힐까?

45초 동안 집게로 인형을 모으는 로컬 프로토타입입니다.

- 실행: `npm ci`, `npm run dev -- --host 127.0.0.1`
- 검증: `npm test`, `npm run build`
- 조작: 화면 드래그 또는 방향키로 이동, 버튼/스페이스로 뽑기

크기·무게·잡은 위치가 안정성에 영향을 줍니다. 상품구에 실제로 들어간 인형만 점수와 카드를 줍니다. 브랜드 6종마다 스타일링 2개, 태도 2개로 총 24개의 창작 문구가 있습니다. 같은 브랜드의 직전 카드와 같은 문구는 연속으로 나오지 않습니다.

획득 카드가 나타나면 게임 시간이 멈춥니다. 확인 후 계속 뽑을 수 있고, 같은 페이지를 열어둔 동안 아래 ‘내가 뽑은 카드’에서 다시 읽을 수 있습니다. 새로고침하면 카드 목록은 초기화됩니다. 최고점수만 브라우저에 저장됩니다.

`src/cards.ts`에서 문구를 편집합니다. 공식 브랜드 문구나 인용문이 아닌 게임용 창작 콘텐츠입니다.
